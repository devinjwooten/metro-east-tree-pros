# Brand Guidelines

## Brand position

Metro East Tree Pros should feel like a calm, capable, local professional.
Customers should come away believing the team will protect their property,
communicate clearly, and leave the site clean.

The voice is direct, helpful, knowledgeable, and respectful. Avoid hype,
fear-driven language, unverified superlatives, and generic contractor clichés.

## Visual system

The current UI uses a restrained natural-service palette:

| Role | Current implementation |
| --- | --- |
| Primary action | `bg-green-700`, `text-green-700` |
| Primary action hover | `hover:bg-green-800` |
| Light surface | `bg-white` |
| Alternating surface | `bg-slate-50` |
| Dark contrast surface | `bg-gray-900` |
| Main text | `text-gray-900` |
| Supporting text | `text-gray-600` / `text-gray-300` on dark surfaces |

Do not introduce new brand colors without an approved system-level reason.
Maintain adequate contrast, particularly green text on white and text over
hero images.

## Typography and spacing

Use bold, outcome-led headlines with readable supporting copy. The current
pattern is `text-4xl` to `text-5xl` for section headings, `font-black` for
major headlines, and `leading-7` or `leading-8` for body copy. Keep body copy
to a comfortable measure with `max-w-2xl` or `max-w-3xl`.

Use generous page sections (`py-20 sm:py-24`), `max-w-7xl px-6` containers,
and large rounded corners. Card styles should remain intentional: soft borders,
clean white surfaces, and restrained slate-tinted shadows.

## Logo and image use

Use the existing logo asset without stretching, recoloring, or placing it on a
low-contrast surface. Favor real crew, equipment, completed-work, and service
context photography. Images must be relevant, optimized, stable in layout, and
given purposeful alt text. Never treat an unrelated service image as a permanent
replacement for a missing asset.

## CTA language

Preferred primary labels: “Request a Free Estimate,” “Call Now,” and “Explore
Tree Removal.” Keep one primary and one secondary action in each CTA group.
Emergency pages should foreground calling while clearly directing life-safety
or downed-power-line emergencies to 911 and the utility provider.
