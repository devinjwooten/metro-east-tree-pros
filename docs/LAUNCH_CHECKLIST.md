# Launch Checklist

## Business verification

- [ ] Business name, legal entity, phone, email, service area, hours, and
      emergency-service claims are verified.
- [ ] License, insurance, credentials, guarantees, pricing, and financing
      statements are approved and current.
- [ ] All testimonials, project photos, logos, and review references are real,
      approved, and accurately attributed.

## Content and SEO

- [ ] Every public route has a unique H1, useful headings, valid internal links,
      and a clear primary CTA.
- [ ] Title tags, descriptions, canonical configuration, and social metadata
      are unique and use the confirmed production domain.
- [ ] The sitemap, robots policy, and redirects are intentionally configured.
- [ ] Structured data is validated and only contains verified, visible facts.
- [ ] Sample review content has been removed or clearly labeled.

## Conversion and forms

- [ ] Every phone number uses the correct `tel:` link and works on a phone.
- [ ] Contact and estimate forms submit to a configured, tested destination.
- [ ] Success, error, validation, spam protection, and notification flows are
      tested end to end.
- [ ] CTA destinations, form analytics, and call tracking are verified.

## Accessibility and responsive QA

- [ ] Keyboard navigation, visible focus states, headings, labels, and contrast
      have been checked.
- [ ] Desktop, tablet, and narrow mobile layouts have been visually reviewed.
- [ ] Image alt text is meaningful and decorative images are excluded from the
      accessibility tree.
- [ ] Motion, hero overlays, and interactive FAQ behavior remain usable.

## Technical quality

- [ ] `npm run lint` passes with no warnings or errors.
- [ ] `npm run build` passes, including TypeScript validation.
- [ ] All internal routes and image paths resolve.
- [ ] Production assets are optimized; no unnecessary scripts or large media are
      loaded.
- [ ] Error pages, 404 behavior, analytics consent, security headers, and
      monitoring are configured as appropriate.

## Post-launch

- [ ] Confirm the deployed site, metadata, forms, phone links, and analytics.
- [ ] Submit or verify the production site in appropriate search tools.
- [ ] Monitor conversion events, index coverage, page performance, and customer
      feedback during the first 30 days.
